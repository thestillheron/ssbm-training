# Timing (tuned live): the intro movie plays first and the title screen only
# appears about 85 s after boot, so wait 90 s. From there `start` always lands
# on a stable screen: during the intro or a demo it returns to the title, and
# a second `start` reaches the main menu. (If the title were already showing,
# the first `start` would reach the main menu and the second would select
# 1-P Mode, so do not shorten the first wait.)
