# 04: Steps 3–5: all four options, several heights, a height range

**What to build:** The next [curriculum](../../../docs/glossary.md#glossary_curriculum) drills, after the pairs:

1. All four options at one height. Vanish on, 70 reps, pass mark 56.
2. Two or three heights: one-option drills first (vanish off, 35 reps, pass mark 28), then an all-four drill (vanish on, 70 reps, pass mark 56).
3. A height range with all four options. Vanish on, 70 reps, pass mark 56.

All on Final Destination, each with a description of what it trains and what to look for.

The design calls are the developer's: which heights, which range, and which options get a several-heights drill. The developer fills them in below (authoring with the layout editor if the layouts differ from the default), and the agent transcribes them into the drill table and writes the descriptions.
